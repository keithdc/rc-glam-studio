Drop photos here for the About carousel (left of "Where Artistry Meets Elegance").
The site picks them up automatically (restart `npm run dev` if needed).

Rank / order with a number prefix. Lower number shows first:

  01-eye-master.jpg
  02-bridal-look.jpg
  03-editorial.jpg

Use two digits (01, 02, 03) so 10 still sorts after 09.

Accepted files: .jpg  .jpeg  .png  .webp
Do not put README.txt in the slide list — only image files are used.
