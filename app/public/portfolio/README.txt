Drop photos into the matching collection folder.
The site picks them up automatically (restart `npm run dev` if needed).

  bridal/      Bridal looks
  editorial/   Editorial / magazine glam
  events/      Debuts, prom, galas, parties
  everyday/    Soft glam, office, date night
  lessons/     Classes and tutorials

Home page Highlights shows one card per collection (cover = first photo).
Click a card to open that collection on the Portfolio page.

Accepted files: .jpg  .jpeg  .png  .webp
Name files anything you like, e.g. beach-wedding.jpg
